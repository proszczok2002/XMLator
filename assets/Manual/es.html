Crear el primer archivo de respuesta

XMLator guarda las opciones de instalación en Autounattend.xml. El instalador de Windows lee este archivo al arrancar desde el medio de instalación. Puede pedirte los datos que dejes para configurar manualmente.

  1. Elige la versión de Windows, la arquitectura y la edición que coincidan con la imagen de instalación.
  2. En la primera prueba, elige las particiones manualmente para identificar el disco en el instalador.
  3. Configura el idioma, la región y la cuenta. Si decides añadir cuentas en el asistente, incluye una cuenta de administrador local.
  4. Revisa el resumen, abre la vista previa y guarda el XML. En ese mismo paso puedes crear una unidad USB de arranque a partir de un ISO.
Ejemplo para un equipo típico con Windows 11 Pro

Elige Windows 11, x64, Pro y UEFI / GPT. Configura el idioma y la distribución del teclado. Usa la selección manual de particiones en la primera prueba y comprueba que el ISO incluya Pro.

Teclado y lector de pantalla

Usa Tab y Mayús+Tab para cambiar de control, las flechas para elegir en una lista y Espacio para marcar o desmarcar una casilla. El título indica el paso actual. Usa Atrás y Siguiente para moverte entre pasos.

  • Ctrl+S prepara la exportación a XML. Ctrl+Mayús+S guarda un perfil INI.
  • Ctrl+O abre un perfil. Ctrl+Fin abre el resumen después de comprobar los ajustes de las cuentas.
  • El menú Ayuda contiene los Métodos abreviados de teclado y este manual. En el navegador puedes desplazarte por encabezados o usar el buscador. Usa Espacio o Intro sobre un ejemplo plegado para abrirlo.

Windows, licencia, edición y clave de producto

Elige el sistema que instalarás en el equipo de destino. La mayoría de los equipos Intel y AMD usan x64. Windows en Arm usa ARM64. x86 corresponde a 32 bits. Las opciones dependen del sistema y de la arquitectura.

  • Decide si quieres aceptar la licencia en el archivo de respuesta o durante la instalación.
  • Elige en la lista la edición, por ejemplo Home o Pro. Usa un nombre de imagen o un índice exacto si conoces el contenido de ese ISO.
  • La clave de instalación puede intervenir en la elección de la imagen. La clave de activación activa Windows después de instalarlo. Omitir la pregunta o indicar una clave de instalación no concede una licencia.

Modo de arranque, disco y particiones

Elige primero el modo de arranque. La unidad USB que prepares con XMLator usará ese mismo modo.

  • UEFI / GPT permite elegir manualmente, crear las particiones de sistema y una partición C grande, o crear las particiones de sistema con C y D. En el último caso, indica el tamaño de C. La partición D ocupará el espacio que quede.
  • Legacy BIOS / MBR permite elegir manualmente o crear una partición C activa en todo el disco. Contiene Windows y los archivos de arranque. Los requisitos de Microsoft para Windows 11 incluyen UEFI.
  • EFI contiene archivos de arranque, MSR reserva espacio para Windows y la partición de recuperación opcional contiene WinRE. El plan muestra el orden y el tamaño de las particiones.

Crear una distribución predefinida borra todas las particiones del disco seleccionado. Comprueba el número del disco en el programa de instalación. Para conservar particiones existentes o identificar el disco en el equipo de destino, elige Seleccionar manualmente en el programa de instalación.

Ejemplo de tamaño para C

Introduce 102400 MiB para asignar 100 GiB a C. Ctrl+A selecciona el número y Tab aplica el cambio. D ocupa el espacio que dejen C y las particiones de sistema.

Idioma, región y nombre del equipo

El idioma del asistente, el idioma del ISO y la configuración de Windows instalado son opciones distintas. Cambia el idioma del asistente desde el menú Idioma o los ajustes. El paso de idioma y región configura Windows, el teclado y la zona horaria.

Elige la distribución que se usará al escribir el nombre de cuenta o la contraseña. Un nombre de equipo propio ayuda a identificarlo en la red. Mantén el ajuste predeterminado si quieres que Windows lo elija.

Cuentas locales y primer inicio de sesión

Si eliges Sí. Añadir cuentas en el asistente., añade una cuenta y escribe su nombre o pide que se solicite al exportar. Debe haber al menos una cuenta local con permisos de administrador. Si la lista está vacía, el asistente bloquea el avance y lleva el foco al botón para añadir una cuenta. Para dejar el nombre para más tarde, añade la cuenta con esa opción.

  • Con el inicio de sesión manual, eliges la cuenta después de instalar Windows. El inicio de sesión único usa el primer administrador añadido. Las reglas de contraseña dependen de Windows.
  • Las opciones de omitir pantallas y configurar sin conexión requieren un administrador local. Windows Server puede pedir una contraseña para la cuenta Administrador integrada.
  • El perfil INI recuerda qué datos debe solicitar. Introduce las contraseñas al exportar. El XML puede contenerlas. Base64 es reversible, así que guarda el XML con cuidado.

Configuración avanzada

Las opciones dependen del sistema seleccionado. Los ajustes iniciales controlan qué pantallas compatibles se omiten. Revisa el resumen si cambias las cuentas o la red.

  • Las aplicaciones marcadas se seleccionan para su eliminación. Comprueba si harán falta Microsoft Store, funciones de voz o componentes que use el lector de pantalla.
  • El programa de instalación estándar utiliza el archivo de respuesta. La opción DISM aplica la imagen en Windows PE y prepara el arranque según la distribución. Para preparar el disco manualmente en modo DISM, utiliza DiskPart.
  • Los componentes XML personalizados y los scripts son para implementaciones preparadas. Comprueba su contenido y la fase en la que se ejecutan.

Controladores, archivos y scripts OEM

Añade controladores de Windows PE si el instalador los necesita para acceder a un disco u otro dispositivo. Indica por separado los controladores para Windows instalado. También puedes adjuntar archivos y scripts para fases concretas de la instalación.

Al crear la unidad USB se añaden estos archivos. Al guardar el XML puedes elegir otra carpeta para la estructura del medio. Con el método estándar, los archivos OEM van en sources\$OEM$ y los controladores de Windows PE en $WinPEDriver$. Conserva la estructura al copiarla.

Resumen, archivos XML y perfiles INI

Revisa el sistema, la edición, el modo de arranque, el plan de particiones, las cuentas y la configuración inicial. Abre la vista previa del XML. El nombre propuesto al guardar el archivo de respuesta es Autounattend.xml.

Guarda un perfil INI para volver a abrir las opciones en XMLator. El instalador de Windows lee el XML en la raíz del medio de instalación.

Reutilizar un perfil en varios equipos

Guarda un perfil comprobado que solicite el nombre de cuenta al exportar. Abre ese perfil en cada caso, comprueba el disco y la edición, y escribe los datos que correspondan al guardar el XML.

Imágenes ISO y unidades USB de arranque

Selecciona la unidad USB y un ISO local o una fuente disponible. Con Descargar un ISO desde el sitio de Microsoft, elige la versión y el idioma. La disponibilidad depende del sistema, la arquitectura y el servicio de Microsoft. Windows 11 26H2 se ofrece para x64 y ARM64. En proszczok.pl selecciona un archivo compatible del catálogo.

  1. Antes de pulsar Crear una unidad USB de arranque, comprueba el nombre, la capacidad y el contenido. El formato borra sus datos.
  2. Tras la confirmación, XMLator comprueba el ISO y copia los archivos de instalación, el XML y los extras. El título y la barra de progreso indican la fase.
  3. Arranca el equipo de destino desde esa unidad en el modo elegido en el paso del disco. Responde a las preguntas que dejas para la instalación.

Resolver problemas de instalación

El asistente pide una cuenta

Añade una cuenta de administrador local o configura la cuenta en el instalador. Si quieres introducir el nombre más tarde, pide que se solicite al exportar.

Falta una fuente de ISO o el archivo no coincide

Comprueba la conexión, el sistema, la arquitectura y la edición. Actualiza las fuentes si la opción está disponible. También puedes elegir un ISO local compatible. El instalador detecta las ediciones de esa imagen.

La unidad arranca pero el instalador rechaza el disco

Comprueba la entrada UEFI o Legacy del menú de arranque y compárala con Disco y particiones. Para conservar la distribución existente, usa la selección manual.

El instalador sigue haciendo preguntas

Comprueba el nombre y la ubicación de Autounattend.xml. Las pantallas que dejas para configurar manualmente se muestran según las reglas de la versión de Windows. Consulta los registros de instalación para investigar un error.

Manual y actualizaciones

El manual forma parte de XMLator. Abre Ayuda → Manual de usuario para leerlo en el idioma activo. Funciona sin conexión. Al abrirlo después de actualizar el programa, verás el manual incluido con la versión nueva.

En los ajustes puedes buscar actualizaciones y configurar la búsqueda automática. Consulta los cambios, el código y la documentación pública en el repositorio de XMLator en GitHub.
