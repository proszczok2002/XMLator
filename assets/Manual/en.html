Create your first answer file

XMLator saves your installation choices in Autounattend.xml. Windows Setup reads this answer file when it starts from the installation media. Any choices you leave for manual setup may still be presented as prompts.

  1. Select the Windows version, architecture, and edition that match your installation image.
  2. Use manual partition selection for your first test so you can identify the target drive in Setup.
  3. Choose the language, regional settings, and account setup. If you choose to create accounts in the wizard, add a local administrator.
  4. Review the choices, preview the XML, and save it. The review page can also use an ISO to build a bootable USB drive.
Example for a typical Windows 11 Pro PC

Select Windows 11, x64, Pro, and UEFI / GPT. Pick your language and keyboard layout. Start with manual partition selection and check that the chosen ISO contains Pro.

Keyboard and screen reader

Use Tab and Shift+Tab to move between controls. Use the arrow keys to choose a list item and Space to toggle a checkbox. The window title gives the current step. Use Back and Next to move between steps.

  • Ctrl+S prepares to save the XML file. Ctrl+Shift+S saves an INI profile.
  • Ctrl+O opens a profile. Ctrl+End opens the review after checking your account choices.
  • The Help menu contains Keyboard commands and this manual. In the browser, navigate by heading or use the search field. Press Space or Enter on a collapsed example title to expand it.

Windows, license, edition, and product key

Choose the Windows version for the destination PC. Most Intel and AMD PCs use x64, and Windows on Arm uses ARM64. x86 means 32-bit Windows. The choices depend on the version and architecture.

  • Choose whether to accept the license terms in the answer file or during Windows Setup.
  • Choose an edition from the list, such as Home or Pro. Use an exact image name or index if you know how images are laid out in your specific ISO.
  • A setup key can affect image selection. An activation key activates the installed system. Skipping the key prompt or supplying a setup key does not grant a license.

Boot mode, disk, and partitions

Choose the installer boot mode first. The USB drive you create with XMLator uses that same mode.

  • UEFI / GPT offers manual selection, system partitions and one large C partition, or system partitions with C and D. Enter the size of C for the split layout. D takes the space left after the other partitions.
  • Legacy BIOS / MBR offers manual selection or one active C partition across the whole disk, including Windows and the boot files. Microsoft requires UEFI for Windows 11.
  • EFI contains boot files, MSR reserves space for Windows, and the optional WinRE partition contains the Windows recovery environment. Check the partition plan for the order and sizes.

Creating a preset layout erases all partitions on the selected disk. Verify the disk number in Setup. If you intend to preserve existing partitions or identify the disk on the destination computer, choose Manually in Setup.

Example C partition size

Type 102400 in the C partition size field to allocate 100 GiB. Ctrl+A selects the number and Tab applies it. D takes the space left after C and the system partitions.

Language, region, and computer name

The wizard language, ISO language, and installed Windows settings serve different purposes. Change the wizard language from the Language menu or Settings. The language and region step controls Windows locale, keyboard layout, and time zone.

Choose the keyboard layout the user will expect when entering a name or password during Setup. Set a computer name if you need to identify the PC on a network. Keep the default if Windows should choose it.

Local accounts and first sign-in

No. Set up the account in Setup. leaves account setup to Windows during installation. Windows may offer a Microsoft account according to the edition and setup conditions.

With Yes. Add accounts in the wizard., select Add account… and enter a name or set the wizard to ask for it on export. Add at least one local account with administrator permissions. An empty list stops navigation and moves focus to Add account. For a name entered on export, add an account with that option enabled.

  • With manual sign-in, choose the account after Setup. One-time sign-in uses the first added administrator account. Password rules depend on the version of Windows.
  • The supported screen-skipping and offline setup options require a local administrator. Windows Server may also need a password for the built-in Administrator.
  • An INI profile remembers which details to ask for. Enter passwords when exporting. The XML may contain passwords. Base64 encoding is reversible, so treat the file as sensitive.

Advanced settings

Available options depend on the version of Windows. Initial setup settings control the supported prompts. Review them after changing account or network settings.

  • Checked apps are selected for removal. Consider whether the user needs Microsoft Store, speech features, or components used by a screen reader.
  • Standard Windows Setup consumes the answer file. The DISM option applies the image in Windows PE and creates boot files for the chosen layout. Use DiskPart to prepare the disk manually in DISM mode.
  • Custom XML components and scripts are for prepared deployments. Review each script and when it runs before using it on the target PC.

OEM drivers, files, and scripts

Add Windows PE drivers when Setup needs them to access a drive or other device. Drivers for the installed Windows image go in the separate field. You can also copy files and schedule scripts at supported stages.

Creating a USB drive includes these files. When saving XML, choose a separate folder for the media structure if you need the added files. In standard Windows Setup, OEM files belong under sources\$OEM$ and Windows PE drivers under $WinPEDriver$. Preserve the folder structure when copying it to the media.

Review, XML, and INI profiles

Review Windows, the edition, boot mode, partition plan, accounts, and the first-run settings. Preview the XML file shows what the file will contain. Save XML suggests Autounattend.xml.

Save INI profile stores your choices for reuse in XMLator. Select Open a saved profile next time to edit them. Windows Setup reads the XML file from the root of the installation media.

Reuse a profile on several computers

Save a tested profile that asks for the account name on export. For each computer, open it, verify the disk and edition, and enter the proper account details when saving the answer file.

ISO images and bootable USB drives

Select the USB device, then choose a local ISO or an available download source. With Download an ISO from Microsoft, choose a release and language. Availability depends on Windows, architecture, and Microsoft's service. Windows 11 26H2 is offered for x64 and ARM64. With proszczok.pl, choose a compatible file from its catalog.

  1. Before selecting Create a bootable USB drive, verify the device name, capacity, and contents. Formatting removes its data.
  2. After confirmation, XMLator checks the image, copies the installation files and the answer file, and adds the OEM files. The title and progress bar report the current stage.
  3. Boot the destination computer from the prepared USB drive in the mode chosen on the disk page. Respond to any prompts you left for manual setup.

Troubleshooting an installation

The wizard asks me for an account

Add a local administrator or choose to configure accounts during Windows Setup. Use the ask-on-export option if the account name will be provided later.

An ISO source disappeared or the image does not match

Check your connection, Windows version, architecture, and edition. Refresh ISO sources when available. You can also choose a compatible local ISO. Setup detects available editions from that image.

The USB boots, but Setup rejects the disk layout

Check whether you selected the UEFI or Legacy entry in the boot menu. Compare it with the mode in Disk and partitions. Use manual partition selection if you want to preserve an existing layout.

Setup still shows prompts

Verify the name and location of Autounattend.xml. Screens you leave for manual setup follow the rules of the Windows version. Windows Setup logs can help you find an error.

The manual and updates

The manual ships with XMLator. Select Help → User manual to open it in the active language. It works offline, and the next time you open it after updating the program you will see the manual for that version.

Use Settings to check for updates and manage automatic checks. The change history, code, and public documentation are in the XMLator repository on GitHub.
