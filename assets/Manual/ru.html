Создание первого файла ответов

XMLator сохраняет параметры установки в Autounattend.xml. Программа установки Windows читает этот файл при загрузке с установочного носителя. Если параметр оставлен для ручной настройки, программа установки может запросить его.

  1. Выберите версию, архитектуру и выпуск Windows, соответствующие установочному образу.
  2. Для первой проверки выберите ручную разметку. Это позволит указать нужный диск во время установки.
  3. Настройте язык, регион и способ создания учётной записи. Если создаёте записи в мастере, добавьте локального администратора.
  4. Проверьте сводку, откройте предварительный просмотр XML и сохраните файл. Здесь же можно подготовить загрузочный USB-накопитель из ISO.
Пример для компьютера с Windows 11 Pro

Выберите Windows 11, x64, Pro и UEFI / GPT. Задайте язык и раскладку клавиатуры. Для первого запуска выберите раздел вручную и проверьте, что выбранный образ содержит выпуск Pro.

Клавиатура и программы чтения с экрана

Tab и Shift+Tab перемещают фокус между элементами. Стрелками выбирайте пункты списка, а пробелом меняйте состояние флажка. Заголовок окна указывает текущий шаг. Кнопки Назад и Далее переключают шаги.

  • Ctrl+S подготавливает сохранение XML. Ctrl+Shift+S сохраняет профиль INI.
  • Ctrl+O открывает профиль. Ctrl+End открывает сводку после проверки учётных записей.
  • В меню Справка есть Клавиатурные команды и это руководство. В браузере перемещайтесь по заголовкам или используйте поиск. Чтобы раскрыть пример, нажмите пробел или Enter на его заголовке.

Windows, лицензия, выпуск и ключ продукта

Выберите систему для целевого компьютера. Большинство процессоров Intel и AMD используют x64. Для Windows на Arm выбирайте ARM64. x86 означает 32-разрядную версию. Набор параметров зависит от системы и архитектуры.

  • Решите, принять ли условия лицензии в файле ответов или во время установки.
  • Выберите выпуск из списка, например Home или Pro. Точное имя или индекс указывайте, если знаете состав конкретного ISO.
  • Ключ установки может влиять на выбор образа. Ключ активации активирует установленную систему. Пропуск запроса либо ввод ключа установки не предоставляет лицензию.

Режим загрузки, диск и разделы

Сначала выберите режим загрузки. USB-накопитель, который создаёт XMLator, будет подготовлен для этого режима.

  • UEFI / GPT позволяет выбрать раздел вручную, создать служебные разделы и один большой C или создать служебные разделы, C и D. Для схемы с C и D укажите размер C. D займёт оставшееся место.
  • Legacy BIOS / MBR предлагает ручной выбор либо один активный раздел C для Windows и загрузочных файлов на весь диск. Microsoft требует UEFI для Windows 11.
  • EFI хранит загрузочные файлы, MSR резервирует место для Windows, а необязательный раздел восстановления содержит WinRE. План показывает порядок и размеры разделов.

Готовая схема удаляет все разделы выбранного диска. Уточните его номер в программе установки. Чтобы сохранить существующие разделы или выбрать диск на целевом компьютере, используйте Выбрать вручную в программе установки.

Пример размера раздела C

Введите 102400 МиБ, чтобы выделить 100 ГиБ для C. Ctrl+A выделяет число, Tab применяет его. D получит место, оставшееся после C и служебных разделов.

Язык, регион и имя компьютера

Язык мастера, язык ISO и параметры установленной Windows задаются отдельно. Язык мастера меняется в меню Язык или в параметрах. На шаге языка и региона задаются региональные параметры Windows, раскладка и часовой пояс.

Выберите раскладку, которой будете пользоваться при вводе имени и пароля. Имя компьютера помогает узнать его в сети. Оставьте настройку по умолчанию, если имя должна назначить Windows.

Локальные учётные записи и первый вход

Нет. Настроить учётную запись в программе установки. оставляет настройку записи для установки Windows. В зависимости от выпуска и условий система может предложить учётную запись Microsoft.

При выборе Да. Добавить учётные записи в мастере. добавьте запись и задайте имя либо включите запрос имени при экспорте. Хотя бы у одной локальной записи должны быть права администратора. Если список пуст, мастер остаётся на этом шаге и переводит фокус на кнопку добавления. Чтобы ввести имя позже, сначала добавьте запись с таким параметром.

  • При ручном входе выберите запись после установки. Однократный вход использует первую добавленную запись администратора. Требования к паролям зависят от Windows.
  • Пропуск поддерживаемых экранов и настройка без Интернета требуют локального администратора. Windows Server может запросить пароль встроенного администратора.
  • INI-профиль запоминает, какие данные нужно запросить. Пароли вводятся при экспорте. XML может содержать пароли. Кодирование Base64 обратимо, поэтому храните файл в защищённом месте.

Дополнительные параметры

Набор настроек зависит от выбранной Windows. Параметры первоначальной настройки позволяют пропускать поддерживаемые экраны. После изменения учётных записей или сети проверьте сводку.

  • Приложения с установленными флажками выбраны для удаления. Проверьте, нужны ли Microsoft Store, речевые функции или компоненты, которые использует программа чтения с экрана.
  • Обычная программа установки читает файл ответов. DISM применяет образ в Windows PE и создаёт загрузочные файлы для выбранной схемы. Для ручной подготовки диска в режиме DISM используйте DiskPart.
  • Собственные XML-компоненты и сценарии предназначены для подготовленного развёртывания. Проверьте содержимое и этап запуска каждого сценария.

Драйверы, файлы и сценарии OEM

Добавьте драйверы Windows PE, если они нужны для доступа к диску или другому устройству во время установки. Драйверы для установленной Windows укажите отдельно. Можно приложить файлы для копирования и сценарии для разных этапов.

При создании USB-накопителя XMLator добавляет нужные файлы. При сохранении XML можно выбрать отдельную папку для структуры носителя. В обычном режиме файлы OEM размещаются в sources\$OEM$, а драйверы Windows PE в $WinPEDriver$. Сохраняйте структуру каталогов при копировании.

Сводка, XML и профили INI

Проверьте систему, выпуск, режим загрузки, план разделов, учётные записи и первоначальные настройки. Откройте предварительный просмотр XML. Имя файла, предложенное при сохранении, — Autounattend.xml.

Сохраните профиль INI, чтобы повторно открыть настройки в XMLator. Программа установки Windows использует XML из корневой папки установочного носителя.

Один профиль для нескольких компьютеров

Сохраните проверенный профиль с запросом имени записи при экспорте. Для каждого компьютера снова откройте его, проверьте диск и выпуск, затем введите нужные данные при сохранении XML.

Образы ISO и загрузочные USB-накопители

Выберите USB-устройство, затем локальный ISO или доступный источник. В пункте Скачать ISO с сайта Microsoft выберите версию и язык. Предложения зависят от системы, архитектуры и доступности службы Microsoft. Windows 11 26H2 предлагается для x64 и ARM64. В каталоге proszczok.pl выберите подходящий файл.

  1. Перед созданием загрузочного USB-накопителя проверьте его имя, ёмкость и содержимое. Форматирование удалит данные с этого устройства.
  2. После подтверждения XMLator проверит образ и скопирует файлы установки, XML и дополнительные файлы. Заголовок окна и индикатор отображают этап.
  3. Загрузите компьютер с накопителя в режиме, выбранном на странице диска. Ответьте на вопросы, оставленные для ручной настройки.

Устранение неполадок при установке

Мастер просит добавить учётную запись

Добавьте локального администратора или настройте запись при установке Windows. Включите запрос при экспорте, если имя будет известно позже.

Источник ISO отсутствует или образ не подходит

Проверьте подключение, версию Windows, архитектуру и выпуск. Обновите список источников, если команда доступна. Можно выбрать подходящий локальный ISO. Программа установки определяет выпуски в этом образе.

USB-накопитель загружается, но схема диска не принимается

Сравните пункт UEFI или Legacy в меню загрузки с параметром на странице Диск и разделы. Для сохранения существующих разделов выберите ручную разметку.

Программа установки продолжает задавать вопросы

Проверьте имя и расположение файла Autounattend.xml. Оставленные для ручной настройки экраны зависят от версии Windows. Сведения об ошибках доступны в журналах установки.

Руководство и обновления

Руководство входит в состав XMLator. Откройте Справка → Руководство пользователя, чтобы читать на выбранном языке. Руководство работает без Интернета. После обновления программы откройте его ещё раз, чтобы получить текст новой версии.

В параметрах можно проверить обновления и настроить автоматическую проверку. История изменений, исходный код и документация доступны в репозитории XMLator на GitHub.
