Créer un premier fichier de réponses

XMLator enregistre les choix d’installation dans Autounattend.xml. Le programme d’installation de Windows lit ce fichier au démarrage sur le support. Une question peut s’afficher si vous conservez la configuration manuelle de l’option correspondante.

  1. Choisissez la version, l’architecture et l’édition de Windows correspondant à votre image d’installation.
  2. Pour le premier essai, choisissez la sélection manuelle des partitions. Vous pourrez identifier le disque dans le programme d’installation.
  3. Réglez la langue, la région et le compte. Pour créer des comptes dans l’assistant, ajoutez au moins un administrateur local.
  4. Vérifiez le récapitulatif, affichez l’aperçu et enregistrez le XML. Vous pouvez aussi créer une clé USB amorçable à partir d’un ISO.
Exemple pour un PC sous Windows 11 Pro

Choisissez Windows 11, x64, Pro et UEFI / GPT. Définissez la langue et la disposition du clavier. Commencez par le choix manuel des partitions et vérifiez que l’ISO contient l’édition Pro.

Clavier et lecteur d’écran

Tab et Maj+Tab déplacent le focus entre les commandes. Utilisez les flèches dans une liste et la barre d’espace pour cocher ou décocher une case. Le titre de la fenêtre indique l’étape actuelle. Les boutons Précédent et Suivant changent d’étape.

  • Ctrl+S prépare l’enregistrement du XML. Ctrl+Maj+S enregistre un profil INI.
  • Ctrl+O ouvre un profil. Ctrl+Fin ouvre le récapitulatif après vérification des comptes.
  • Le menu Aide contient les Raccourcis clavier et ce guide. Dans le navigateur, naviguez par titre ou utilisez la recherche. Appuyez sur Espace ou Entrée sur le titre d’un exemple pour le déplier.

Windows, licence, édition et clé de produit

Choisissez le système de l’ordinateur cible. La plupart des PC Intel et AMD utilisent x64. Windows sur Arm utilise ARM64. x86 désigne la version 32 bits. Les choix varient selon la version et l’architecture.

  • Choisissez d’accepter les conditions de licence dans le fichier de réponses ou pendant l’installation.
  • Sélectionnez une édition telle que Home ou Pro. Un nom d’image exact ou un index est utile si vous connaissez le contenu de votre ISO.
  • La clé d’installation peut influer sur le choix de l’image. La clé d’activation active le système installé. Ignorer la demande de clé ou fournir une clé d’installation n’accorde pas de licence.

Mode de démarrage, disque et partitions

Sélectionnez d’abord le mode de démarrage. La clé USB créée par XMLator utilise le même mode.

  • UEFI / GPT propose le choix manuel, les partitions système avec une grande partition C ou les partitions système avec C et D. Pour C et D, saisissez la taille de C. D occupe l’espace restant.
  • Legacy BIOS / MBR propose le choix manuel ou une partition C active sur tout le disque. Elle contient Windows et les fichiers de démarrage. Microsoft exige le mode UEFI pour Windows 11.
  • La partition EFI contient les fichiers de démarrage. MSR réserve de l’espace pour Windows. La partition de récupération facultative contient WinRE. Le plan indique l’ordre et la taille des partitions.

Une disposition prédéfinie efface toutes les partitions du disque sélectionné. Vérifiez le numéro du disque dans le programme d’installation. Choisissez Choisir manuellement dans le programme d’installation pour conserver des partitions ou identifier le disque sur le PC cible.

Exemple de taille pour C

Saisissez 102400 Mio pour attribuer 100 Gio à C. Ctrl+A sélectionne le nombre. Tab applique la valeur. D prend l’espace laissé par les partitions système et C.

Langue, région et nom de l’ordinateur

La langue de l’assistant, celle de l’ISO et les réglages de Windows installé sont distincts. Changez la langue de l’assistant dans le menu Langue ou les paramètres. L’étape de langue et de région définit les réglages régionaux, le clavier et le fuseau horaire de Windows.

Choisissez la disposition qui servira à saisir le nom du compte et son mot de passe. Un nom d’ordinateur personnalisé permet de reconnaître le PC sur le réseau. Gardez le réglage par défaut si Windows doit attribuer le nom.

Comptes locaux et première ouverture de session

Non. Créez le compte dans le programme d’installation. laisse Windows configurer le compte pendant l’installation. Selon l’édition et les conditions d’installation, Windows peut proposer un compte Microsoft.

Avec Oui. Ajouter les comptes dans l’assistant., ajoutez un compte et renseignez son nom ou demandez de le saisir à l’exportation. Il faut au moins un compte local doté des droits d’administrateur. Si la liste est vide, l’assistant bloque le passage à l’étape suivante et place le focus sur l’ajout d’un compte. Pour saisir le nom à l’exportation, ajoutez le compte avec cette option.

  • En mode manuel, choisissez le compte après l’installation. L’ouverture automatique de session a lieu une seule fois et utilise le premier compte d’administrateur ajouté. Les règles de mot de passe dépendent de Windows.
  • Le saut de certaines pages et la configuration hors connexion nécessitent un administrateur local. Windows Server peut aussi demander un mot de passe pour le compte Administrateur intégré.
  • Le profil INI retient les données à demander. Saisissez les mots de passe à l’exportation. Le XML peut contenir des mots de passe et Base64 est réversible. Protégez donc le fichier.

Paramètres avancés

Les options varient selon Windows. Les réglages de première configuration permettent d’ignorer certaines pages prises en charge. Relisez le récapitulatif après un changement de compte ou de réseau.

  • Les applications cochées sont sélectionnées pour la suppression. Vérifiez si le Microsoft Store, les fonctions vocales ou les composants du lecteur d’écran sont nécessaires.
  • Le programme d’installation standard utilise le fichier de réponses. DISM applique l’image dans Windows PE et crée les fichiers de démarrage pour la disposition choisie. Utilisez DiskPart pour préparer manuellement le disque en mode DISM.
  • Les composants XML et les scripts personnalisés servent aux déploiements préparés. Vérifiez le contenu et le moment d’exécution de chaque script.

Pilotes, fichiers et scripts OEM

Ajoutez des pilotes Windows PE si le programme d’installation en a besoin pour accéder à un disque ou à un autre périphérique. Indiquez séparément les pilotes destinés au Windows installé. Vous pouvez aussi joindre des fichiers à copier et des scripts à exécuter à certaines étapes.

La création de la clé USB ajoute ces fichiers. Lors de l’enregistrement du XML, choisissez un dossier distinct pour la structure du support. En mode standard, les fichiers OEM se placent dans sources\$OEM$ et les pilotes Windows PE dans $WinPEDriver$. Conservez cette arborescence en copiant les fichiers.

Récapitulatif, XML et profils INI

Vérifiez Windows, l’édition, le mode de démarrage, le plan des partitions, les comptes et la première configuration. Affichez l’aperçu du XML. Le nom de fichier proposé à l’enregistrement est Autounattend.xml.

Enregistrez un profil INI pour réutiliser vos choix dans XMLator. Le programme d’installation lit le XML à la racine du support d’installation.

Réutiliser un profil sur plusieurs ordinateurs

Enregistrez un profil vérifié qui demande le nom du compte à l’exportation. Rouvrez-le pour chaque ordinateur, vérifiez le disque et l’édition puis indiquez les données du compte lors de l’enregistrement du XML.

Images ISO et clés USB amorçables

Choisissez le périphérique USB, puis un ISO local ou une source disponible. Avec Télécharger un ISO depuis le site de Microsoft, choisissez la version et la langue. L’offre dépend de Windows, de l’architecture et du service Microsoft. Windows 11 26H2 est proposé pour x64 et ARM64. Avec proszczok.pl, choisissez un fichier compatible dans le catalogue.

  1. Avant de choisir Créer une clé USB amorçable, vérifiez le nom, la capacité et le contenu du périphérique. Le formatage efface ses données.
  2. Après confirmation, XMLator contrôle l’image et copie les fichiers d’installation, le fichier de réponses et les ajouts. Le titre et la barre de progression indiquent l’étape.
  3. Démarrez le PC cible sur la clé dans le mode choisi pour les partitions. Répondez aux questions laissées à l’installation.

Résoudre un problème d’installation

L’assistant demande un compte

Ajoutez un administrateur local ou choisissez de créer le compte lors de l’installation. Si le nom doit être saisi plus tard, activez la demande à l’exportation.

Une source ISO manque ou l’image ne correspond pas

Vérifiez la connexion, Windows, l’architecture et l’édition. Actualisez les sources ISO si la commande est disponible. Vous pouvez sélectionner un ISO local compatible. Le programme d’installation détecte les éditions présentes dans cet ISO.

La clé démarre mais le programme refuse la disposition

Comparez l’entrée UEFI ou Legacy dans le menu de démarrage du PC avec le mode dans Disque et partitions. Utilisez le choix manuel si vous souhaitez conserver des partitions.

Le programme d’installation pose toujours des questions

Vérifiez le nom et l’emplacement de Autounattend.xml. Les réglages laissés à la configuration manuelle suivent les règles de votre version de Windows. Les journaux d’installation aident à rechercher une erreur.

Guide et mises à jour

Le guide est fourni avec XMLator. Ouvrez Aide → Guide d’utilisation pour accéder au texte dans la langue active. Le guide fonctionne hors connexion. Après une mise à jour de l’application, rouvrez-le pour consulter la version fournie avec celle-ci.

Les paramètres permettent de rechercher des mises à jour et de configurer la vérification automatique. Les changements, le code et la documentation publique se trouvent dans le dépôt XMLator sur GitHub.
