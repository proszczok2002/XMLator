创建第一个应答文件

XMLator 将安装选项保存在 Autounattend.xml 中。从安装介质启动时，Windows 安装程序会读取应答文件。留待手动配置的项目仍可能在安装过程中出现提示。

  1. 选择与安装映像对应的 Windows 版本、体系结构和版本类型。
  2. 首次测试时，选择手动分区，以便在安装程序中确认目标磁盘。
  3. 设置语言、区域和帐户创建方式。如果选择在向导中创建帐户，请至少添加一个本地管理员。
  4. 复查摘要，预览并保存 XML。也可以在同一步骤用 ISO 制作可启动的 U 盘。
Windows 11 专业版示例

选择 Windows 11、x64、Pro 和 UEFI / GPT。设置语言与键盘布局。首次尝试时手动选择分区，并检查 ISO 是否包含专业版。

键盘和屏幕阅读器

使用 Tab 和 Shift+Tab 在控件之间切换。用方向键在列表中选择，用空格键切换复选框。窗口标题会显示当前步骤。按上一步或下一步来切换步骤。

  • Ctrl+S 准备保存 XML。Ctrl+Shift+S 保存 INI 配置文件。
  • Ctrl+O 打开配置文件。Ctrl+End 检查帐户设置后打开摘要。
  • 在帮助菜单中可以找到键盘操作和本手册。浏览手册时，可以按标题浏览，也可以搜索。在折叠的示例标题上按空格键或 Enter 展开。

Windows、许可、版本类型和产品密钥

选择要在目标计算机上安装的 Windows。大多数 Intel 和 AMD 计算机使用 x64。Windows on Arm 使用 ARM64。x86 用于 32 位 Windows。向导选项随版本和体系结构而变化。

  • 选择在应答文件中接受许可条款，或在安装时接受。
  • 从列表选择家庭版或专业版等版本类型。了解特定 ISO 中的映像时，可以输入确切的映像名称或索引。
  • 安装密钥可能影响映像选择。激活密钥用于激活已安装的 Windows。跳过密钥提示或提供安装密钥本身并不会授予许可证。

启动模式、磁盘和分区

先选择安装介质的启动模式。XMLator 制作的启动 U 盘会使用同一模式。

  • UEFI / GPT 提供手动选择、系统辅助分区加一个大 C 分区，以及系统辅助分区加 C 和 D 分区。创建 C 和 D 时，请指定 C 分区大小。D 分区使用剩余空间。
  • Legacy BIOS / MBR 提供手动选择，也可以创建占据整个磁盘的活动 C 分区，其中包含 Windows 和启动文件。Microsoft 要求 Windows 11 使用 UEFI。
  • EFI 分区存放启动文件，MSR 是 Microsoft 保留分区，可选的恢复分区存放 Windows 恢复环境（WinRE）。分区计划会显示顺序和大小。

应用预设布局会删除所选磁盘上的所有分区。 请在安装程序中核对磁盘编号。如需保留现有分区或在目标计算机上确认磁盘，请选择在安装程序中手动选择。

C 分区大小示例

输入 102400 MiB，为 C 分配 100 GiB。按 Ctrl+A 选中数值，再按 Tab 应用。D 分区使用 C 分区和系统辅助分区以外的剩余空间。

语言、区域和计算机名称

向导语言、ISO 语言和安装后的 Windows 设置各自独立。可以在语言菜单或设置中更改向导语言。语言和区域步骤可设置 Windows 的区域、键盘布局和时区。

请选用适合输入帐户名和密码的键盘布局。自定义计算机名称有助于在网络上识别设备。如果希望 Windows 分配名称，请保留默认设置。

本地帐户和首次登录

否。在安装程序中设置帐户。将帐户设置留到安装过程。根据 Windows 版本类型与安装条件，安装程序可能会提示使用 Microsoft 帐户。

选择是。在向导中添加帐户。后，请添加帐户并输入名称，或选择导出时询问名称。至少需要一个具有管理员权限的本地帐户。列表为空时，向导会停留在当前步骤，焦点移到添加帐户按钮。若想稍后输入名称，请先添加帐户并启用导出时询问。

  • 手动登录时，安装完成后自行选择帐户。单次登录会使用第一个添加的管理员帐户。密码规则取决于 Windows。
  • 跳过受支持的初始设置页面和脱机设置都需要本地管理员。Windows Server 也可能要求内置 Administrator 帐户的密码。
  • INI 配置文件会记住所需的提示，密码在导出时输入。XML 文件可能包含密码。Base64 编码可以还原，请妥善保管应答文件。

高级设置

可用设置取决于选择的 Windows 版本。首次设置选项可跳过受支持的页面。更改帐户或网络设置后，请检查摘要。

  • 勾选的应用会被列为移除对象。请确定是否需要 Microsoft Store、语音功能或屏幕阅读器使用的组件。
  • 标准 Windows 安装程序使用应答文件。DISM 选项在 Windows PE 中应用映像，并为选定布局生成启动文件。在 DISM 模式下手动准备磁盘时，请使用 DiskPart。
  • 自定义 XML 组件和脚本用于事先规划的部署。请在使用前检查脚本及其运行阶段。

OEM 驱动程序、文件和脚本

安装程序需要额外驱动才能访问磁盘或设备时，请添加 Windows PE 驱动程序。为安装后的 Windows 单独指定驱动程序。还可以添加待复制的文件和在指定阶段运行的脚本。

制作 U 盘时会包含这些文件。保存 XML 时，可以另选目录以保存介质结构。在标准安装模式下，OEM 文件位于 sources\$OEM$，Windows PE 驱动程序位于 $WinPEDriver$。复制文件时应保留目录结构。

摘要、XML 和 INI 配置文件

检查 Windows 版本、版本类型、启动模式、分区计划、帐户和首次设置。通过 XML 预览检查内容。保存应答文件时，建议的文件名是 Autounattend.xml。

保存 INI 配置文件，以便在 XMLator 中重新打开和修改设置。Windows 安装程序读取安装介质根目录中的 XML 应答文件。

在多台计算机上复用配置

保存经过测试并且在导出时询问帐户名的配置文件。每次重新打开配置，检查磁盘和版本类型，再在保存 XML 时输入该计算机的帐户信息。

ISO 映像和可启动的 U 盘

选择 USB 设备，然后选用本地 ISO 或可用的下载来源。在从 Microsoft 下载 ISO中选择版本和语言。下载是否可用取决于 Windows、体系结构及 Microsoft 服务。Windows 11 26H2 提供 x64 和 ARM64 映像。在 proszczok.pl 中可从目录选择匹配的文件。

  1. 制作启动 U 盘前，请核对设备名称、容量和内容。格式化会删除 U 盘上的数据。
  2. 确认后，XMLator 检查映像并复制安装文件、应答文件和附加文件。标题和进度条会显示当前阶段。
  3. 以磁盘步骤中选择的模式从 U 盘启动目标计算机，然后回答留待手动配置的提示。

排查安装问题

向导提示添加帐户

添加本地管理员，或者选择在安装 Windows 时设置帐户。要在稍后提供名称，请启用导出时询问。

缺少 ISO 来源或映像不匹配

检查网络、Windows 版本、体系结构和版本类型。刷新 ISO 来源的命令可用时，可以重新检查。也可以选用匹配的本地 ISO。安装程序会识别映像中包含的版本类型。

U 盘能启动，但安装程序拒绝磁盘布局

检查启动菜单中选的是 UEFI 还是 Legacy，并与磁盘和分区步骤中的模式对照。需要保留已有分区时，请手动分区。

安装程序仍然需要回答问题

检查 Autounattend.xml 的名称和位置。手动设置页面依照所选 Windows 版本的规则显示。遇到错误时，可以查看 Windows 安装日志。

手册和程序更新

手册随 XMLator 提供。通过帮助 → 用户手册打开当前语言的手册。手册可脱机使用。更新程序后再次打开手册，即可阅读新版本自带的内容。

在设置中可以检查更新和配置自动检查。更改记录、源代码及公开文档都在 GitHub 上的 XMLator 仓库中。
