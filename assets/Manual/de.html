Die erste Antwortdatei

XMLator speichert die Installationsoptionen in Autounattend.xml. Das Windows-Setup liest diese Datei beim Start vom Installationsmedium. Einstellungen, die Sie zur manuellen Auswahl belassen, können während der Installation abgefragt werden.

  1. Wählen Sie die Windows-Version, die Architektur und die Edition passend zum Installationsabbild.
  2. Wählen Sie für den ersten Versuch die manuelle Partitionierung. So können Sie den richtigen Datenträger im Setup bestimmen.
  3. Stellen Sie Sprache, Region und die Kontoeinrichtung ein. Wenn Sie Konten im Assistenten hinzufügen, legen Sie auch ein lokales Konto mit Administratorrechten an.
  4. Prüfen Sie die Zusammenfassung, öffnen Sie die XML-Vorschau und speichern Sie die Antwortdatei. Aus einem ISO können Sie dort auch ein startfähiges USB-Laufwerk erstellen.
Beispiel für einen PC mit Windows 11 Pro

Wählen Sie Windows 11, x64, Pro und UEFI / GPT. Stellen Sie Sprache und Tastaturlayout ein. Verwenden Sie für den ersten Versuch die manuelle Datenträgerauswahl. Prüfen Sie, ob das ISO die Edition Pro enthält.

Tastatur und Screenreader

Tab und Umschalt+Tab wechseln das Steuerelement. Mit den Pfeiltasten wählen Sie einen Listeneintrag. Die Leertaste schaltet ein Kontrollkästchen um. Der Fenstertitel nennt den aktuellen Schritt. Verwenden Sie Zurück und Weiter, um den Schritt zu wechseln.

  • Strg+S bereitet das Speichern der XML-Datei vor. Strg+Umschalt+S speichert ein INI-Profil.
  • Strg+O öffnet ein Profil. Strg+Ende wechselt nach Prüfung der Kontoeinrichtung zur Zusammenfassung.
  • Unter Hilfe finden Sie die Tastaturbefehle und das Handbuch. Im Browser können Sie nach Überschriften navigieren und Kapitel suchen. Klappbare Beispiele öffnen Sie mit der Leertaste oder Eingabetaste.

Windows, Lizenz, Edition und Product Key

Wählen Sie Windows für den Zielcomputer. Die meisten Intel- und AMD-PCs verwenden x64. Windows auf Arm benötigt ARM64. x86 steht für 32 Bit. Die verfügbaren Optionen hängen von der Version und Architektur ab.

  • Legen Sie fest, ob die Lizenzbedingungen per Antwortdatei oder während der Installation akzeptiert werden.
  • Wählen Sie möglichst eine Edition wie Home oder Pro aus der Liste. Ein genauer Abbildname oder Index ist für ein bekanntes ISO vorgesehen.
  • Ein Installationsschlüssel kann die Abbildauswahl beeinflussen. Ein Aktivierungsschlüssel aktiviert das installierte System. Das Überspringen der Schlüsselabfrage oder ein Installationsschlüssel ersetzt keine Lizenz.

Startmodus, Datenträger und Partitionen

Wählen Sie zuerst den Startmodus des Installationsmediums. XMLator richtet ein von ihm erstelltes USB-Laufwerk für denselben Modus ein.

  • UEFI / GPT bietet die manuelle Auswahl, Systempartitionen mit einer großen Partition C oder Systempartitionen mit C und D. Für C und D geben Sie die Größe von C ein. D belegt den restlichen Speicherplatz.
  • Legacy BIOS / MBR bietet die manuelle Auswahl oder eine aktive Partition C für Windows und die Startdateien auf dem ganzen Datenträger. Microsoft setzt für Windows 11 UEFI voraus.
  • EFI enthält die Startdateien. MSR ist für Windows reserviert. Die optionale Wiederherstellungspartition enthält WinRE. Der Partitionsplan zeigt die Reihenfolge und die Größen.

Ein vorgegebenes Layout löscht alle Partitionen des gewählten Datenträgers. Kontrollieren Sie seine Nummer im Windows-Setup. Verwenden Sie Manuell während der Installation auswählen, wenn Sie vorhandene Partitionen behalten oder den Datenträger erst am Zielcomputer bestimmen möchten.

Beispiel für die Größe von C

Geben Sie 102400 MiB für 100 GiB ein. Strg+A markiert die Zahl. Tab übernimmt sie. D nutzt den Platz, der nach C und den Systempartitionen frei ist.

Sprache, Region und Computername

Die Sprache des Assistenten, die Sprache des ISO und die Einstellungen des installierten Windows sind eigene Optionen. Die Assistentensprache ändern Sie über Sprache oder die Einstellungen. Im Schritt für Sprache und Region wählen Sie die Windows-Spracheinstellungen, das Tastaturlayout und die Zeitzone.

Wählen Sie das Tastaturlayout, das bei der Eingabe von Name und Kennwort verwendet werden soll. Ein eigener Computername erleichtert die Zuordnung im Netzwerk. Bei der Standardeinstellung legt Windows den Namen fest.

Lokale Konten und erste Anmeldung

Nein. Konto während der Installation einrichten. überlässt die Kontoeinrichtung dem Windows-Setup. Je nach Edition und Installationsbedingungen kann Windows ein Microsoft-Konto anbieten.

Bei Ja. Konten im Assistenten hinzufügen. fügen Sie ein Konto hinzu und geben seinen Namen ein oder lassen den Namen beim Export abfragen. Mindestens ein lokales Konto benötigt Administratorrechte. Ist die Liste leer, bleibt der Assistent auf dieser Seite und setzt den Fokus auf die Schaltfläche zum Hinzufügen. Für eine spätere Namenseingabe muss das entsprechende Konto bereits in der Liste stehen.

  • Bei manueller Anmeldung wählen Sie das Konto nach dem Setup. Die einmalige Anmeldung verwendet das erste hinzugefügte Administratorkonto. Die Kennwortregeln hängen von Windows ab.
  • Unterstützte Optionen für das Überspringen von Ersteinrichtungsseiten oder die Offlineeinrichtung setzen ein lokales Administratorkonto voraus. Windows Server kann außerdem ein Kennwort für das integrierte Administratorkonto anfordern.
  • Ein INI-Profil merkt sich die Abfragen. Kennwörter geben Sie beim Export ein. Die XML-Datei kann Kennwörter enthalten. Base64 lässt sich zurückwandeln. Schützen Sie die Antwortdatei entsprechend.

Erweiterte Einstellungen

Welche Optionen verfügbar sind, hängt von der Windows-Version ab. In den Einstellungen für die Ersteinrichtung können Sie unterstützte Seiten überspringen. Prüfen Sie die Zusammenfassung, wenn Sie Konten oder Netzwerkoptionen ändern.

  • Markierte Apps sind zum Entfernen ausgewählt. Prüfen Sie, ob der Microsoft Store sowie Sprach- und Screenreader-Funktionen benötigt werden.
  • Das standardmäßige Windows-Setup verarbeitet die Antwortdatei. Die DISM-Option wendet das Abbild in Windows PE an und erstellt die Startdateien für das gewählte Layout. Bei manueller Vorbereitung im DISM-Modus verwenden Sie DiskPart.
  • Eigene XML-Komponenten und Skripte sind für vorbereitete Bereitstellungen gedacht. Prüfen Sie Inhalt und Ausführungszeitpunkt vor der Verwendung.

OEM-Treiber, Dateien und Skripte

Fügen Sie Windows-PE-Treiber hinzu, wenn das Setup sie für einen Datenträger oder ein anderes Gerät benötigt. Treiber für das installierte Windows geben Sie getrennt an. Sie können auch Dateien kopieren und Skripte in bestimmten Phasen ausführen lassen.

Beim Erstellen des USB-Laufwerks werden die benötigten Dateien hinzugefügt. Wenn Sie nur XML speichern, können Sie einen eigenen Ordner für die Medienstruktur wählen. Bei Standard-Setup kommen OEM-Dateien unter sources\$OEM$ und Windows-PE-Treiber unter $WinPEDriver$. Behalten Sie diese Ordnerstruktur beim Kopieren bei.

Zusammenfassung, XML und INI-Profile

Prüfen Sie Windows, Edition, Startmodus, Partitionsplan, Konten und Ersteinrichtung. Nutzen Sie die XML-Vorschau. Beim Speichern der Antwortdatei schlägt XMLator den Namen Autounattend.xml vor.

Speichern Sie ein INI-Profil, um die Einstellungen erneut im Assistenten zu öffnen. Das Windows-Setup liest die XML-Datei aus dem Stammordner des Installationsmediums.

Ein Profil für mehrere Rechner

Speichern Sie ein geprüftes Profil mit der Option, den Kontonamen beim Export abzufragen. Öffnen Sie es für jeden Rechner, prüfen Sie Datenträger und Edition und geben Sie die passenden Kontodaten beim Speichern ein.

ISO-Abbild und startfähiges USB-Laufwerk

Wählen Sie das USB-Gerät und geben Sie ein vorhandenes ISO an oder wählen Sie eine verfügbare Downloadquelle. Bei ISO von Microsoft herunterladen wählen Sie Version und Sprache. Das Angebot hängt von Windows, der Architektur und dem Microsoft-Dienst ab. Windows 11 26H2 wird für x64 und ARM64 angeboten. Bei proszczok.pl wählen Sie eine passende Datei aus dem Katalog.

  1. Prüfen Sie Name, Kapazität und Inhalt, bevor Sie Startfähiges USB-Laufwerk erstellen wählen. Beim Formatieren werden die Daten auf dem USB-Laufwerk gelöscht.
  2. Nach der Bestätigung prüft XMLator das Abbild und kopiert Installationsdateien, Antwortdatei und Zusätze. Fenstertitel und Fortschrittsanzeige nennen die Phase.
  3. Starten Sie den Zielcomputer im gewählten UEFI- oder Legacy-Modus vom USB-Laufwerk. Beantworten Sie die Fragen, die Sie zur manuellen Auswahl belassen haben.

Probleme während der Installation

Der Assistent verlangt ein Konto

Fügen Sie ein lokales Administratorkonto hinzu oder wählen Sie die Kontoeinrichtung im Setup. Einen späteren Namen geben Sie über die Abfrage beim Export an.

Eine ISO-Quelle fehlt oder das Abbild passt nicht

Prüfen Sie Internetverbindung, Windows-Version, Architektur und Edition. Aktualisieren Sie die ISO-Quellen, wenn die Option angeboten wird. Sie können ein passendes lokales ISO auswählen. Das Setup erkennt die Editionen im verwendeten Abbild.

Das USB-Laufwerk startet, das Setup lehnt die Partitionierung ab

Vergleichen Sie den UEFI- oder Legacy-Eintrag im Startmenü des Computers mit dem Schritt Datenträger und Partitionen. Wählen Sie manuell, um vorhandene Partitionen zu erhalten.

Das Setup zeigt weiterhin Fragen

Prüfen Sie den Namen und Speicherort von Autounattend.xml. Offene Einstellungen werden nach den Regeln der gewählten Windows-Version abgefragt. Die Setup-Protokolle helfen bei der Fehlersuche.

Handbuch und Programmupdates

Das Handbuch gehört zum Programm. Öffnen Sie es über Hilfe → Benutzerhandbuch in der aktuellen Sprache. Es funktioniert offline. Wenn Sie das Handbuch nach einem Programmupdate öffnen, erhalten Sie die mit dieser Version gelieferte Fassung.

In den Einstellungen können Sie nach Updates suchen und die automatische Suche festlegen. Änderungen, Quellcode und öffentliche Dokumentation stehen im XMLator-Repository auf GitHub.
